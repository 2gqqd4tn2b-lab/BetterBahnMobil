    Automatisch auf GitHub speichern

    Einmal einrichten, danach speichert diese Seite neue und entfernte Zugänge selbst. Du brauchst dafür einen Zugangsschlüssel (Token) von GitHub, der nur dieses eine Repository ändern darf.

    1. Öffne auf GitHub oben rechts dein Profilbild → Settings → ganz unten Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    2. Name: Split-Suche Admin. Expiration: 1 Jahr (oder nach Wunsch).
    3. Bei „Repository access“ Only select repositories wählen und auswählen.
    4. Bei „Permissions“ → Repository permissions → Contents auf Read and write stellen.
    5. Ganz unten Generate token, den Token kopieren und hier einfügen.

    Der Token wird nur auf diesem Gerät gespeichert, verschlüsselt mit deinem Admin-Zugang. Auf GitHub landet er nie.
